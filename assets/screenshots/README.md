# Screenshot Guide

This directory is reserved for screenshots used in the README and project presentation materials.

The repository does not currently include the following files, so they should be added manually before publishing the project:

1. `home.png` — main NavAssist home screen
2. `perception.png` — perception test screen showing ML Kit detections
3. `map_builder.png` — map builder interface with marked points
4. `navigation.png` — navigation screen and progress/instruction UI
5. `settings.png` — settings screen with tuning options

Recommended practice:
- Use a real device screenshot or emulator capture from the same app state
- Keep the visual consistent with the app’s dark high-contrast theme
- Use a clean background and include only the relevant interface area
- Avoid editing or generating fake screenshots

When the files are added, they should be referenced using relative paths like:

- `assets/screenshots/home.png`
- `assets/screenshots/perception.png`
- `assets/screenshots/map_builder.png`
- `assets/screenshots/navigation.png`
- `assets/screenshots/settings.png`
